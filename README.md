# Curation Reports
This repository contains curation reports for Pathoplexus. Curation reports are any suspected errors or mislabelled data associated with sequences on Pathoplexus. Anyone can [make an issue](https://github.com/pathoplexus/curation_reports/issues/new/choose) to report something about a sequence or metadata!

Curation reports are evaluated by our team of curators; if two agree that the weight of evidence suggests the current data is incorrect, a decision is considered made. They can then prepare a revision request and this can be actioned according to the [Curator Standard Operating Procedure](https://pathoplexus.org/docs/how-to/curator-sop). 

Note that accepted changes can be applied immediately to sequences coming to Pathoplexus from NCBI, but changes to directly-submitted sequences can only be accepted by the original submitting group.
